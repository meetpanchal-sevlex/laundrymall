# 🎨 Master Directory of Top Free Open-Source UI Repositories

This document tracks the authoritative open-source repositories, component engines, and design systems for building ultra-premium web applications (Linear, Apple, and Awwwards standard).

---

## 🏆 1. Complete Production Repositories (Full Stack & Design Systems)

### 1. Midday.ai
- **GitHub:** [midday-ai/midday](https://github.com/midday-ai/midday)
- **Tech Stack:** Next.js, Tailwind CSS, Framer Motion, Radix UI, TypeScript
- **Key Assets:**
  - Site of the Day award winner
  - Dark mode color architecture (`#0C0C0C`, `border-white/10`)
  - Financial bento cards and metric indicator pills
  - Fluid animated dialogs and drawer transitions

### 2. Dub.co
- **GitHub:** [dubinc/dub](https://github.com/dubinc/dub)
- **Tech Stack:** Next.js App Router, Tailwind CSS, Framer Motion
- **Key Assets:**
  - Standard-setting SaaS UX flows (featured on Mobbin)
  - Interactive `Cmd+K` command palette
  - Spring-physics animated dropdowns and popovers
  - Subtle mouse-following radial hover highlights

### 3. Cal.com
- **GitHub:** [calcom/cal.com](https://github.com/calcom/cal.com)
- **Tech Stack:** Next.js, Tailwind CSS, Prisma, TypeScript
- **Key Assets:**
  - The gold standard for appointment booking and scheduling UX
  - Clean multi-step booking wizards and responsive time-slot grids

## ⚡ 2. Component Engines & Motion Libraries (Copy-Paste)

### 4. Magic UI
- **GitHub:** [magicuidesign/magicui](https://github.com/magicuidesign/magicui)
- **Website:** [magicui.design](https://magicui.design/)
- **Signature Components:**
  - **Border Beam:** High-energy glowing light beam tracing container borders
  - **Bento Grid:** Interactive asymmetrical grid cards with hover tilts
  - **Marquee:** Smooth infinite ticker for partner logos and reviews
  - **Animated Beam:** Dynamic SVG curves showing data flow between tech nodes

### 5. Aceternity UI
- **GitHub:** [aceternity/ui](https://github.com/aceternity/ui)
- **Website:** [ui.aceternity.com](https://ui.aceternity.com/)
- **Signature Components:**
  - **Spotlight:** Dynamic flashlight effect following cursor position
  - **3D Pin & Glare Card:** 3D perspective tilt on hover
  - **Floating Dock:** Apple macOS-inspired dock navigation bar
  - **Background Beams / Sparkles:** Subtle ambient background particles

### 6. Motion Primitives
- **GitHub:** [ibelick/motion-primitives](https://github.com/ibelick/motion-primitives)
- **Website:** [motion-primitives.com](https://motion-primitives.com/)
- **Signature Components:**
  - **Morphing Dialog:** Smooth card expansion into full-screen dialogs using `layoutId`
  - **Fluid Tabs:** Sliding background pill for tab navigation
  - **Spring Accordion:** Physics-based collapsible sections

### 7. Origin UI
- **Website:** [originui.com](https://originui.com/)
- **Signature Components:**
  - 200+ micro-crafted form inputs, switches, toggles, and notification toasts
